# PayFlow Studio

PayFlow Studio is a responsive smart checkout and merchant dashboard
frontend simulation built using HTML, CSS, and JavaScript.

It demonstrates a complete e-commerce-style checkout flow with
cart management, checkout validation, simulated payment processing,
persistent order history, and merchant analytics.

> Note: This project is a frontend simulation. It does not process
> real payments or store real payment/card credentials.

## Features

- Responsive landing page
- Product listing
- Product search
- Category filtering
- Shopping cart
- Quantity management
- Automatic order calculation
- Checkout form validation
- Multiple simulated payment methods
- Simulated payment processing
- Successful/failed payment states
- Order history
- Order details modal
- Merchant dashboard
- Revenue analytics
- Success-rate calculation
- Average order value
- Most-used payment method
- Dark/light mode
- Browser LocalStorage persistence
- Responsive mobile layout
- User notifications

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
